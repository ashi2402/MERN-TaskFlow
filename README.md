# TaskFlow — MERN Stack Project

TaskFlow is a project and task management application built while learning the MERN stack.

## Tech Stack

- **Frontend:** React, TypeScript, Vite, CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas (planned)
- **Version Control:** Git and GitHub
- **Deployment:** Render (planned)

## Features

- Create tasks with a title, description, priority, and status
- View tasks fetched from the Express API
- Mark tasks as completed
- Delete tasks
- Responsive task management interface

## Local Development

### Frontend

```bash
cd taskflow-frontend
npm install
npm run dev
```

### Backend

```bash
cd taskFlow-backend
npm install
npm run dev
```

The frontend runs on `http://localhost:5173` and the backend on `http://localhost:3000`.

## Learning Goals

Build a full-stack application while learning React, REST APIs, Express middleware, MongoDB, authentication, testing, and deployment.
